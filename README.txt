MS TEX & GARMENTS — WEBSITE PROJECT
===================================

Project pages (7):
1. index.html       - Home
2. about.html       - Our Story
3. collections.html - Collections
4. products.html    - Products
5. craft.html       - Our Craft / Manufacturing process
6. careers.html     - Tailor, embroidery and garment helper vacancies
7. contact.html     - Contact and enquiry form

HOW TO RUN
1. Extract the ZIP file.
2. Open the MS_Tex_Garments folder.
3. Double-click index.html, or open it with Chrome.
4. Use the top navigation to visit all seven pages.

TECHNOLOGIES
- HTML5
- CSS3 (responsive layout and mobile navigation)
- JavaScript (mobile menu and email enquiry form)

IMPORTANT
- Product and fashion photographs are loaded from Unsplash image URLs, so an internet
  connection is required to display them.
- Google Fonts are also loaded online.
- The enquiry form opens the visitor's default email application. It does not save
  enquiries to a database. For live online order processing, payment, stock management,
  or server-side form submission, a backend and database must be added.
- The listed vacancies are sample recruitment categories for the website. Confirm actual
  open positions before publishing them as current vacancies.
